# Feature metrics

BK-05 measures birth, age, activation, retirement, novelty, redundancy, consumers, useful lineage, utility per byte/work, churn, dormancy, and obsolete protection. Human-semantic names are not utility. Redundancy is identical representation identity. Missing utility stays unavailable.

Controlled fixtures at `fixtures/feature-metrics/v1/expected-outcomes.json` identify useful, redundant, dormant, and retired cases exactly.
