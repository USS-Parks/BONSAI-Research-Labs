# Option metrics

BK-07 measures success, duration, return, stopping-state value, controllability, reliability, redundancy, planning participation, marginal gain, and acquisition/maintenance cost. Creating an option is not a benefit. Harmful options have negative marginal gain. Unused options have no executions. Redundancy is representation identity among used non-harmful options.

The committed fixture at `fixtures/option-metrics/v1/expected-outcomes.json` classifies reliable, redundant, harmful, and unused options.
