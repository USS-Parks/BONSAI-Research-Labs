# ADR 0009: macOS monitor/terminate enforcement

- Status: accepted
- Date: 2026-08-24
- Owner: BONSAI maintainers
- Source: approved PSPR v0.3 BM-08

macOS does not provide a Job Object or cgroup equivalent in canonical mode. Enforceable controls are monitor/terminate with measured overshoot. Claiming Windows/Linux hard-cap parity is forbidden.

## Supersession

Only a dated, user-approved PSPR addendum and replacement ADR may introduce a privileged macOS hard-limit primitive.
