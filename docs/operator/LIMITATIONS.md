# Limitations and non-claims

Read this before quoting any BONSAI result.

BONSAI v1 is **not a hostile-native-code sandbox** (D-21 / P-05). Process isolation protects the instrument from faulty adapters. Ambient native code can still use OS APIs outside BONSAI-controlled handles.

This workspace does **not** claim:

- instrument completion while 72-hour physical-host L evidence is not-run;
- OaK / Oak Lab algorithm reproduction;
- C4/C5 pass as a trophy;
- crates.io, PyPI, git tag, or marketing publication (OD-03);
- physical Job Object, delegated cgroup, or Apple-silicon energy qualification from hosted CI;
- E2/E3 energy, AMD/Intel collectors, cluster execution, or a SaaS dashboard (P-01–P-08).

Missing measurements stay unavailable. Failed seeds stay visible. A valid M1 bundle is a heartbeat, not an evaluated-agent success.
