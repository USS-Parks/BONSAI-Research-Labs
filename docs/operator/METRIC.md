# Metrics

Metrics are versioned contracts. Derived report numbers must come from deterministic tables.

Start at the [metric registry](../metrics/REGISTRY.md). Primary families:

- [behavior](../metrics/PRIMARY-BEHAVIOR-METRICS.md)
- [resource and overhead](../metrics/RESOURCE-AND-OVERHEAD-METRICS.md)
- [continual learning](../metrics/CONTINUAL-LEARNING-METRICS.md)
- [failure criteria](../metrics/FAILURE-CRITERIA.md)
- [statistical aggregation](../metrics/STATISTICAL-AGGREGATION.md)

Estimates bind the specification hash. Unavailable measurements stay unavailable. Do not backfill zeros. Energy stays E0 unless a collector is qualified.
